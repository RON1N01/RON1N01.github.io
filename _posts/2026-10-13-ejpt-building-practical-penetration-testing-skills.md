On October 9, 2026, I earned the **eLearnSecurity Junior Penetration Tester (eJPT)** certification from INE, marking an important milestone in my offensive security development.

Following my CompTIA Security+ certification in November 2025, I began preparing for the eJPT in April 2026 to transition from foundational security knowledge toward practical penetration testing.

## Technical Skills

My preparation focused on developing hands-on proficiency across several core penetration testing disciplines:

- **Network Enumeration:** Identifying hosts, open ports, services, and potential attack surfaces using Nmap.
- **Vulnerability Assessment:** Investigating exposed services, misconfigurations, and potential exploitation paths.
- **Exploitation:** Applying exploitation techniques using Metasploit and manual methods.
- **Web Application Security:** Performing basic web application enumeration and testing using tools such as Burp Suite.
- **Pivoting:** Understanding network segmentation and techniques for accessing additional systems through compromised hosts.
- **Post-Exploitation:** Conducting further enumeration and assessing access within compromised environments.

## Examination Experience

The eJPT is a hands-on certification that evaluates practical penetration testing skills in a simulated network environment.

The examination reinforced the importance of a structured methodology:

**Reconnaissance → Enumeration → Vulnerability Analysis → Exploitation → Post-Exploitation**

One of my key takeaways was that successful exploitation depends heavily on accurate enumeration and understanding the target environment rather than relying exclusively on automated tools.

## What's Next

With **Security+ and eJPT** completed, my next objective is the **OffSec Certified Professional (OSCP)** certification.

My continued development will focus on:

- Advanced Windows and Linux privilege escalation
- Active Directory enumeration and exploitation
- Network pivoting and lateral movement
- Web application penetration testing
- Offensive security methodology and reporting

The eJPT represents my first practical penetration testing certification and establishes a foundation for progressing toward professional penetration testing and red team operations.
